## 📖 Overview

Pokédex is a responsive web application that lets users explore Pokémon and view their information through a clean and modern interface.

The app fetches real-time Pokémon data from the official **PokéAPI** and presents it in an easy-to-use Pokédex interface.

## ✨ Features

* 🔍 Search Pokémon by name or ID
* 📋 Browse Pokémon with detailed information
* 📊 View base stats and Pokémon types
* 🖼️ Display Pokémon artwork and sprites
* ⚡ Fast and responsive React interface
* 📱 Mobile-friendly design
* 🌐 Data fetched from PokéAPI

## 🚀 Getting Started

```bash
git clone https://github.com/Harsh-cc/MyPokedex.git
cd MyPokedex
npm install
npm run dev
```

Open the local URL provided by Vite in your browser.

## 🌐 API

This project uses **PokéAPI**, a free and open Pokémon REST API.
